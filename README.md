# Esherify

Turn any Droste image into an MC Escher spiral, right in your browser.

A WebGL conformal-map sandbox with a 4-stage guided walkthrough: frame the nested copies, unroll the spiral via the complex log, twist the strip, and exponentiate back to a seamless loop.

## Run locally

```bash
bun install
bun dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

Next.js · TypeScript · WebGL2 · Tailwind · Zustand · ffmpeg.wasm
